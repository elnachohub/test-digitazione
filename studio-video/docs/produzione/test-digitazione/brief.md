# Brief — Test di digitazione

Scritto dal regista. Primo cliente di prova della squadra video: il sito è
nostro, quindi possiamo usarlo come vetrina di ciò che sappiamo fare.

| | |
|---|---|
| Cliente | Test di digitazione (sito del titolare di Studio Video) |
| Sito pubblico | https://elnachohub.github.io/test-digitazione/ |
| Copia locale per le catture | `http://127.0.0.1:8790/index.html` — se non risponde, dalla cartella che contiene `index.html` del test (la radice del repository) avvia `python3 -m http.server 8790 --bind 127.0.0.1` |
| Pubblico | studenti, chi lavora al computer, chi vuole scrivere più veloce; italiano e inglese |
| Obiettivo | una sola azione: **aprire il sito e fare un test adesso** |
| Tono | giocoso, sfidante ("quanto sei veloce?"), mai scolastico |
| Cosa NON dire | classifiche mondiali, numeri di utenti, recensioni: non esistono. Niente "gratis per sempre" se il sito non lo dice (che è gratis e senza registrazione si può dire solo se il sito lo mostra o lo dice il README del test) |

## Video da consegnare

1. **Promo verticale** — `promo` · 9:16 (Reels, TikTok, Shorts) · 15–20 s.
   Gancio di sfida, 3 punti forti, il sito in un telefono, invito.
2. **Tutorial** — `tutorial` · 16:9 (YouTube, pagina del sito) · 25–40 s.
   Come si fa un test: scelta della modalità/durata, si scrive, si guardano
   i risultati. Passi veri, con le coordinate prese dalle catture.

Scadenza: questa sessione. Musica: nessuna (non abbiamo brani con diritti chiari).
