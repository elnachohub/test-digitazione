# Test di digitazione

Test di velocità di digitazione su tastiera QWERTY, con frasi di senso compiuto
in italiano e inglese, tre livelli, profili, punteggi e grafico di velocità,
errori e fluidità.

**Gioca:** https://elnachohub.github.io/test-digitazione/

Profili e risultati restano solo nel tuo browser: il sito non ha un server e
non raccoglie dati personali.
